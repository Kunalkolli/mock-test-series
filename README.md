# Mock Test Series — free starter website

This is a static website starter. It includes a responsive homepage and three sample practice quizzes with a timer, automatic scoring, and answer explanations.

## Publish using GitHub Pages (free)

1. Sign in to https://github.com
2. Click the **+** button in the top-right, then choose **New repository**.
3. Name the repository `mock-test-series` (or another name you prefer).
4. Set visibility to **Public** and create the repository.
5. On the repository page, click **Add file** → **Upload files**.
6. Upload `index.html` from this folder. You may also upload this README.
7. Click **Commit changes**.
8. Open the repository's **Settings** → **Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Select branch `main` and folder `/(root)`, then click **Save**.
11. Wait a few minutes and refresh the Pages screen. GitHub will show the published website URL, usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Important limitations

- This is a front-end demo. Scores and answers are handled in the browser.
- There are no student accounts, secure paid access, online payments, shared leaderboard, or admin database yet.
- Do not put private question banks, confidential answer keys, API keys, or payment secrets in this static site.
- Before accepting payments, add a secure backend and verify payment callbacks server-side.
